# 发布到 Steam 创意工坊参考

官方文档：https://docs.wallpaperengine.io/en/scene/first/publishing.html

## 发布流程（指导用户操作）

1. 在编辑器中打开要发布的壁纸项目。
2. 菜单「创意工坊」→「准备上传」（英文：Workshop → Prepare for publishing）。
3. 填写/检查以下必填项：
   - **标题**：与项目一致，清晰可搜索。
   - **描述**：功能、个性化选项说明、素材来源/授权声明（用了他人物素必须注明授权）。
   - **预览图**：16:9 比例、**至少 1280x720**；静态图（jpg/png）或 GIF——**GIF 不得超过 1MB**。可以用编辑器自动生成的预览图，但建议自制。
   - **内容分级**：Everyone / Questionable / Mature（如实选，错误分级会被下架）。
   - **标签**：至少选一个分类标签。
   - **可见性**：首次发布建议 `Private（私有）` 自查，确认后再改 Public。
4. 勾选同意创意工坊条款 → 上传。上传完成会打开创意工坊页面。
5. 分享给朋友：把创意工坊物品页链接发给对方即可（私有物品仅好友可见需在页面设置）。

## 更新已发布的壁纸

同一入口：编辑器打开项目 →「创意工坊」→「准备上传」→ 检测到项目已绑定创意工坊物品后选择「更新」，可顺带更新描述/预览图。**不要删除重传**（会丢订阅数和评论）。

## 发布前自查清单

- [ ] `project.json`：title/description/contentrating/tags 齐全，`visibility` 为 private 先自查
- [ ] 预览图 16:9 ≥1280x720（GIF ≤1MB）
- [ ] 壁纸在 1920x1080 下运行流畅（编辑器性能面板 / Chrome 任务管理器检查 CPU、GPU、内存）
- [ ] 用户属性（颜色/开关等）都能正常生效
- [ ] 音频可视化壁纸在无声时表现正常（不卡在最后一帧）
- [ ] 使用了第三方素材 → 已在描述中注明来源与授权
- [ ] 无侵权内容（影视/动漫版权素材是工坊下架最常见原因）

## 常见问题

- **上传按钮灰色/报错**：Steam 客户端未登录或离线模式；预览图不符合规格。
- **发布后壁纸页显示模糊**：预览图分辨率低于 1280x720。
- **被 审核/下架**：检查分级与版权素材。
